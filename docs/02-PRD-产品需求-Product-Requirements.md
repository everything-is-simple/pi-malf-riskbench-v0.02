## §1 概述

### 1.1 项目定位

AI MALF RiskBench v0.02 是在 v0.01 五组件（290 passed）基础上，以 pi-coding-agent 为 AI 底座、Electron 为桌面壳，组装 MALF 结构测量 → RISK 风险量化 → AI 信号发现 → BENCH 基准验证闭环的**只读风险工作台**。

### 1.2 用户角色

| 角色 | 描述 | 单一性 |
|---|---|---|
| 个人开发者/交易者 | 单一用户，负责数据 curation、风险声明、决策 | 单人单机单写进程 |

### 1.3 三层权威（继承 v0.01）

```
第一层：市场事实（MALF 引擎产出，确定性，不可改写）
  │  产出：WaveStructuralSnapshot 44 字段 + signals 事件流
  │  特性：整数价格、严格不等式、lineage_hash 确定性、honest degradation
  │
第二层：用户声明（用户对市场事实的解读与风险声明，AI 不可修改）
  │  产出：风险声明记录（用户手写或模板辅助）
  │  特性：用户主权，AI 只提醒矛盾，不修改
  │
第三层：AI 解读（AI 对第一层+第二层的解释/总结/提醒，必须标注，不凌驾前两层）
  │  产出：自然语言解读、回测报告解读、矛盾提醒
  │  特性：明确标注"AI 解读"，失败不阻塞确定性规则
```

## §2 四层业务闭环

### 2.1 MALF — 结构测量仪（基础底座，继承 v0.01）

> 角色：系统唯一的确定性输入层。把原始价格转成结构快照。**只测量，不预测。**

| 需求 ID | 描述 | 优先级 | v0.02 状态 |
|---------|------|:--:|:--:|
| MALF-01 | 读取 TDX `.day` 二进制文件，转换为 PriceBar（全整数） | P0 | ✅ v0.01 已实现 |
| MALF-02 | 逐 bar 调用 MALFCoreEngine.on_bar，产生 CoreStateSnapshot | P0 | ✅ v0.01 已实现 |
| MALF-03 | 组装完整 WaveStructuralSnapshot（44 字段） | P0 | ✅ v0.01 已实现 |
| MALF-04 | lineage_hash 重复性验证（两次运行 hash 一致） | P0 | ✅ v0.01 已实现 |
| MALF-05 | 持久化到 DuckDB snapshots 表（PK symbol,timeframe,bar_dt） | P0 | ✅ v0.01 已实现 |
| MALF-06 | 中断恢复（replay 前缀+跳过已持久化） | P1 | ✅ v0.01 已实现 |
| MALF-07 | 优雅降解（peer_sample<30 → None，不伪造数据） | P0 | ✅ v0.01 已实现 |
| MALF-08 | v0.02 通过 Adapter 桥接进 pi 扩展层，供只读 Viewer 查询 | P0 | 📝 v0.02 新建 |

### 2.2 RISK — 风险量化器（中控层）

> 角色：从快照提取风险特征。风险定义为"结构性极端 + 动量方向"，非传统 VaR/CVaR。**只量化，不评分，不产生交易决策。**

| 需求 ID | 描述 | 优先级 | v0.02 状态 |
|---------|------|:--:|:--:|
| RISK-01 | 从 P1 视图提取极端度（rank > 0.80 → 提示非正常状态） | P1 | 📝 v0.02 新建 |
| RISK-02 | 从 P2 视图提取动量方向（accelerating / decelerating / flat） | P1 | 📝 v0.02 新建 |
| RISK-03 | 从 P3 视图提取方向优势（self_dominant / opposite_dominant / balanced） | P1 | 📝 v0.02 新建 |
| RISK-04 | 联合 P1+P2+P3 产生风险提示（极端 + 衰减 + 方向切换 → 高风险区） | P2 | 📝 v0.02 新建 |
| RISK-05 | 风险声明记录（用户手写或模板辅助，AI 不可修改） | P0 | 📝 v0.02 新建 |

### 2.3 AI — 决策辅助与信号发现（上层智能）

> 角色：不做预测，只做信号发现和规则校准。**只辅助，不替代规则，不自主交易。**

| 需求 ID | 描述 | 优先级 | v0.02 状态 |
|---------|------|:--:|:--:|
| AI-01 | 支持 OpenAI-compatible LLM 调用（多 provider，走 pi provider 体系） | P2 | 📝 v0.02 新建 |
| AI-02 | AI 辅助信号规则发现：分析回测中对/错的快照序列 | P2 | 📝 v0.02 新建 |
| AI-03 | LLM 驱动回测报告解读：自然语言总结，标注异常区间 | P3 | 📝 v0.02 新建 |
| AI-04 | 自适应参数校准：根据样本数量动态调整 rank 阈值 | P3 | 📝 v0.02 新建 |
| AI-05 | AI 解读必须明确标注"AI 解读"，不凌驾第一层+第二层 | P0 | 📝 v0.02 新建 |
| AI-06 | AI 失败不阻塞确定性规则（规则优先可证伪） | P0 | 📝 v0.02 新建 |

## §4 非目标（v0.1 明确不做什么）

### 4.1 不做的功能（继承 v0.01 §6.2）

- 不选股、不排名、不推荐标的
- 不输出胜率预测、综合交易分、"27 桶"
- 不生成买卖建议、仓位计算、订单
- 不连接券商、不自动交易
- 不计算真实仓位或 PnL
- 不让 AI 修改 MALF/RISK 层的确定性计算
- 不复制旧系统代码和复杂度

### 4.2 不做的形态（v0.02 新增）

- 不支持多用户、多终端并发、远程协作
- 不做 SaaS、不做 Web 服务
- 不做后台 scheduler/文件 watcher/自动重算
- 不做公网绑定/隧道/云部署
- 不做可写设置中心
- 不做 mobile 适配（只做桌面浏览器设备模拟/同机窗口）
- 不让 AI 自主调用 MALF 引擎写入生产库

### 4.3 用途边界（继承 v0.01）

| 边界 | 说明 |
|---|---|
| research_only | 历史数据模拟、研究验证用途（当前数据固定为此档） |
| verification_only | 确定性规则验证用途（T4 已实现） |
| rejected | 输入完整性失败，整只标的拒绝 |
| operational | **v0.1 硬编码禁用**，需未来独立审批 |

### 4.4 回测绩效指标用途边界（2026-08-05 用户裁决）

BENC-03 的绩效指标（夏普、最大回撤、胜率、盈亏比、年化收益率）属于**研究验证**范畴（历史数据模拟、research_only 用途），**不是**面向用户的买卖建议/收益预测，不接入真实账户，不得用于自动交易。

## §6 风险声明边界（v0.02 新增）

### 6.1 风险声明定义

风险声明是**用户对市场事实（第一层）的解读与风险判断**，属于第二层权威，AI 不可修改。

### 6.2 风险声明记录

| 字段 | 类型 | 说明 |
|---|---|---|
| declaration_id | str | 唯一标识 |
| symbol | str | 标的代码 |
| timeframe | str | 周期 |
| bar_dt | str | 关联 bar 时间 |
| user_text | str | 用户手写或模板辅助的声明文本 |
| linked_snapshot_fields | list[str] | 关联的 snapshot 字段（如 rank/label） |
| created_at | str | 创建时间 |
| ai_interpretation | Optional[str] | AI 解读（必须标注"AI 解读"） |
| ai_interpretation_marked | bool | AI 解读是否已标注 |

### 6.3 风险声明规则

- 用户主权：用户可创建/修改/删除自己的风险声明
- AI 不可修改：AI 只能读取风险声明，不能修改 user_text
- AI 只提醒矛盾：AI 可检测风险声明与市场事实的矛盾并提醒
- AI 解读必须标注：ai_interpretation 字段必须标明"AI 解读"
