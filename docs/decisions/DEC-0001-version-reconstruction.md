# DEC-0001 — v0.01 到 v0.02 的版本重构

> 状态：用户批准起草，待战役 2正式实施时冻结
> 日期：2026-08-05

## 决策

新建独立系统版本 `pi-malf-riskbench-v0.02`，不继续扩展 `ai-malf-riskbench` v0.01 的产品身份。

## 原因

战役 1 的目标是确定性原型、数据管道、信号、回测验证、编排和 MALF 定义闭环；战役 2 的目标是以 Pi 为 AI 底座、以 `malf-engine` 为领域底座，重新构造专属 Agent 工作系统。两者的产品身份、架构边界、依赖策略和验收合同不同。

## 版本分工

```text
v0.01：验证市场事实和 MALF 确定性核心
v0.02：把验证后的核心装配成 Pi-based AI 工作系统
```

## 影响

- v0.01 保持为战役 1 的历史和验证基线；
- v0.02 拥有独立目录、PRD、架构和计划；
- v0.02 不直接复制 v0.01 代码；
- 经过批准的领域事实通过接口和版本合同重新装配；
- T9 作为 v0.01 验证闭环被引用，不作为 v0.02 已完成实现。

## 未决项

- Pi 上游依赖、fork 或源码镜像策略；
- v0.02 首期是否采用 CLI、本地 stdio 或其他桥接；
- 是否进入模型 Provider、Skills、调度和 GUI 能力；
- 研究指标和 AI 层的单独裁决。
